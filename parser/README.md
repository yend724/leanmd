# Parser

A Rust library for generating an Abstract Syntax Tree (AST) from Markdown tokens.

## Supported Syntax

- [x] Paragraphs
- [x] Headings (`#`, `##`, ...)
- [x] Emphasis (`*text*`)
- [x] Bold (`**text**`)
- [x] Inline code (`` `code` ``)
- [x] Code blocks (` ```language meta\ncode``` `)
  - [x] Language specification
  - [x] Meta information
- [x] Blockquotes (`> text`)
- [x] Unordered lists (`- text`)
- [x] Ordered lists (`1. text`)
- [x] Links (`[text](url)`)
- [x] Images (`![text](url)`)
- [x] Horizontal rules (`---`)

## Overview

The parser module takes tokens generated by the lexer module and constructs an Abstract Syntax Tree (AST) that represents the structure and content of the Markdown document. This AST can then be used for rendering or further processing.
