# Lexer

Markdownテキストを字句解析（トークン化）するRustライブラリです。

## サポートする構文

### ブロックレベル要素

- [x] 見出し（`#`, `##`, ...）
- [x] コードブロック（` ``` `）
  - [x] 言語指定
  - [x] メタ情報
- [x] 段落
- [ ] 順序付きリスト
- [ ] 順序なしリスト
- [ ] ブロッククォート
- [ ] 水平線

### インラインレベル要素

- [x] 強調（`*text*`）
- [x] 太字（`**text**`）
- [x] インラインコード（`` `code` ``）
- [ ] リンク
- [ ] 画像
